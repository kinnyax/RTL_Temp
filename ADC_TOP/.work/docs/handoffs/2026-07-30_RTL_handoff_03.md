## Delivered architecture

Eight explicit ADC_CHN instances connect the fixed-eight ADC_REG/ADC_SYNC/ADC_TGC hierarchy. Direction-only port suffixes were removed. ADC_CHN directly instantiates PUB `async_fifo` FWFT (`AS=9`, `DS=512`, `RSTEN=0`, `WC=0`, `RC=0`); `ADC_FIFO` does not exist. The only FIFO reset is `fifo_rst_n = adc_rst_n & ~fifo_clr`.

`afe_rst_n` reaches only ADI `device_reset`; `jesd_rst_n` reaches only ADI link reset. CHN_SYNC was corrected so self-written CDC uses `adc_rst_n`, matching unpack/TGC/FIFO behavior. Normal packets are Header + 256 beats; incomplete abnormal blocks are dropped.

Formatting is intentionally limited to aligned declaration/port punctuation; clean procedural formatting is sufficient, and one-line named PUB CDC instances are explicitly allowed.
